# Задачи

[← Документация](../../README.ru.md) · [English](../en/tasks.md) · **Русский**

Задачи — это markdown-чекбоксы, которые ищутся в выбранной **папке задач**, а пока активен
модуль дневника — и в папке дневника, потому что захваченные задачи живут там. Поддерживаются
маркеры списка `-` и `*`, а у каждой задачи есть **статус из четырёх состояний**, закодированный
символом внутри чекбокса:

| Чекбокс | Статус |
| --- | --- |
| `- [ ]` | К выполнению |
| `- [/]` | В работе |
| `- [x]` | Сделана |
| `- [-]` | Отменена |

```markdown
- [ ] Написать квартальный отчёт 🔼 📅 2025-01-15 #work/reports
    - [ ] Набросать вступление
    - [x] Собрать цифры
- [/] Переписать парсер 🔁 every week 🛫 2025-01-02
- [x] Купить продукты #home ✅ 2025-01-08
```

Чекбоксы с отступом становятся **подзадачами** той задачи, что стоит над ними. Строчные
маркеры (подмножество соглашения популярного плагина *Tasks*):

| Маркер | Что значит |
| --- | --- |
| `⏫` / `🔼` / `🔽` | Срочный / высокий / низкий приоритет (`🔺` и `⏬` читаются как срочный и низкий) |
| `📅 YYYY-MM-DD` | Срок |
| `🛫 YYYY-MM-DD` | Дата начала |
| `⏳ YYYY-MM-DD` | Запланировано на |
| `✅ YYYY-MM-DD` | Дата выполнения (проставляется сама при отметке «сделано») |
| `🔁 <правило>` | Повторение (`daily`, `weekly`, `monthly`, `every N days`…) |
| `⏰ HH:MM` / `⏰ HH:MM-HH:MM` | Время дня, при желании с концом — именно оно ставит задачу на часовую сетку календаря |
| `⏱ 1h25m` | Уже потраченное время (ведёт таймер задачи) |
| `⏲ 45m` | Обратный отсчёт, на который таймер был выставлен в последний раз, — он же плановая длительность на часовой сетке |
| `#тег` (в т.ч. `#a/b`) | Тег — по правилам Obsidian, так что `C#`, `page#anchor` и `#123` тегами не считаются |

Zenith правит строку **только там, где вы что-то изменили**. Всё остальное остаётся как
написано — порядок, пробелы, `📆` вместо `📅` и маркеры, для которых у Zenith нет поля:
`➕` (дата создания), `🆔` (id), `⛔` (зависит от) и `🏁` (что делать по выполнении) из
плагина *Tasks*, `^ссылка-на-блок`, ваши собственные эмодзи. Маркер, которого в строке ещё не
было, встаёт туда, куда его записал бы Zenith, — перед тегами в конце строки.

Выполнение **повторяющейся** задачи проставляет ей дату ✅ и вставляет над ней следующее
повторение со сдвинутыми датами. Новое повторение — это та же строка без того, что
принадлежало выполненному: без отметки ✅, потраченного времени, `🆔`, `⛔` и ссылки на блок
(копия сломала бы всё, что на них ссылается); `➕` становится сегодняшней датой. Задача с
`🏁 delete` после выполнения удаляется — у повторяющейся остаётся следующее повторение вместе
с описанием под ним. Файл может задать **значения по умолчанию** через YAML во фронтматтере
(`priority`, `due`, `tags`); строчные маркеры в самой строке их перекрывают, а правка задачи
не переносит их в строку.

Экран задач добавляет **выбор статуса** в каждой строке, полноценное **окно
создания/правки** (статус, приоритет, теги с автодополнением, даты срока / начала /
планирования, повторение, подзадачи) и **панель статистики** (сделано/всего, в работе,
просрочено, прогресс, серия, активные дни, кольца по статусам и тегам, тепловая карта
выполнения). В строках задач виден свёрнутый счёт подзадач, а панель фильтров умеет сужать
по сроку — включая **без даты**, где и копятся забытые задачи. Новые задачи, созданные из
интерфейса или командой **«Быстро добавить задачу»**, попадают в сегодняшнюю заметку дня,
если у модуля дневника включён захват задач (это по умолчанию — см. [Дневник](journal.md)),
и в `Zenith Inbox.md` в противном случае.

**Ввод обычной фразой.** В быстрой задаче название может нести всё остальное: *Позвонить
маме завтра в 18 !* станет задачей *Позвонить маме* на завтра в 18:00 с приоритетом 🔼.
Каждый понятый кусок показывается чипом под полем, а × на чипе оставляет эти слова в
названии. Что понимается — по-русски и по-английски:

| | Примеры |
| --- | --- |
| Дата → 📅 | `сегодня`, `завтра`, `послезавтра`, `в пятницу`, `пт`, `+3д`, `+2н`, `15.10`, `15.10.2027` · `today`, `tomorrow`, `on fri`, `+3d`, `+2w` |
| Время → ⏰ | `в 18`, `9:30`, `18:00–19:30`, `с 9 до 10:30` · `at 18`, `6pm`, `from 9 to 10` |
| Приоритет | `!` → 🔼, `!!` → ⏫ — отдельно стоящие |
| Повтор → 🔁 | `каждый день/неделю/месяц/год`, `каждые 3 дня`, `ежедневно`, `еженедельно` · `every 2 weeks`, `daily` |

Грамматика нарочно узкая. Голое число — никогда не время (*купить 2 хлеба*), день недели,
названный в этот же день, — это следующая неделя, дата, уже прошедшая в этом году, — это
следующий год, а время или повтор без дня — на сегодня. Всё остальное остаётся в названии:
наполовину понятая фраза и выглядит наполовину понятой, ничего не пропадает. `#теги` — родной
синтаксис задачи, они остаются в названии, а на `#` предлагаются уже существующие. Выключается
в **Задачи → Функции → Ввод обычной фразой**.

> Даты сравниваются в **вашем локальном** часовом поясе, поэтому «Сегодня» и «Просрочено»
> всегда верны.

**Перетаскивание.** У каждой строки задачи и подзадачи есть ручка в блоке действий. Задача
переезжает со всем своим поддеревом и приземляется с отступом того, рядом с чем её бросили,
— так что подзадача, перетащенная к задаче верхнего уровня, повышается, а задача, брошенная
среди чужих детей, вкладывается. Бросить задачу в её *собственное* поддерево нельзя: она
утащила бы детей за собой и осиротила их.

Что означает бросок, зависит от того, куда он пришёлся:

| Куда бросили | Что произойдёт |
| --- | --- |
| Внутрь группы | Меняет порядок строк в файле |
| В другую **умную корзину** | Правит задачу, пока она туда не подойдёт: *Сегодня* ставит срок, *Позже* его снимает, *Сделано* / *Отменено* меняют статус. Выполненная задача, брошенная в активную корзину, открывается заново. |
| В другую **группу-файл** | Переносит задачу в этот файл |
| **Просрочено** | Отказ — в дедлайн, который в прошлом, ничего не запланируешь |

Пустые корзины появляются как цели только пока летит перетаскивание, которое они примут.
Для смены порядка нужна **сортировка: вручную**, потому что любая другая выводит порядок из
данных задачи и перетащенная строка тут же вернулась бы на место. Ручка ещё и получает
фокус: <kbd>↑</kbd>/<kbd>↓</kbd> двигают строку без мыши.
