# Редактор

[← Документация](../../README.ru.md) · [English](../en/editor.md) · **Русский**

То, что делает заметку приятнее писать и читать. Пока это блоки кода.

## Блоки кода

Блок кода между оградами получает:

- шапку с иконкой и названием языка;
- полосу слева цвета языка;
- номера строк;
- кнопку копирования в шапке: она копирует код без оград.

В режиме чтения и в живом просмотре всё одинаково. Режим исходного текста по-прежнему
показывает заметку как текст.

````markdown
```html
<p>Привет</p>
```
````

- **Языки.** Язык задаёт слово после ограды, в любом регистре: `html`, `HTML`, `js`, `py`,
  `ts`, `sh`, `bash`, `rs`, `c++` и другие. Zenith знает больше 300 слов, и примерно у 170
  языков есть иконка и цвет. Незнакомое слово показывается как написано, с простой иконкой.
  Блок без слова подписан как «Текст».
- **Подсветка** своя у Obsidian, в цветах вашей темы. Zenith код не перекрашивает.
- **Длинные строки** в режиме чтения не переносятся: блок прокручивается вбок, чтобы каждый
  номер стоял напротив своей строки. Номера при этом остаются на месте. В живом просмотре
  длинные строки переносятся, как и весь текст заметки.
- **Правка.** В живом просмотре ограды (```` ``` ````) скрыты, пока вы не работаете в блоке, и
  их место занимает шапка. Щёлкните в блок или по его шапке, и они вернутся, чтобы можно было
  сменить язык.
- **Чужие блоки.** Блоки, которые рисует другой плагин, — `dataview`, `mermaid`, `query` и
  подобные — не трогаются.

Выключить оформление или только номера строк можно в *Настройки → Редактор → Функции*.

### Code Styler

[Code Styler](https://github.com/mayurankv/Obsidian-Code-Styler) делает то же самое, и два
плагина нарисовали бы один блок дважды. Пока Code Styler включён, Zenith оставляет блоки кода
ему, о чём пишет на странице своих настроек. Выключите Code Styler в *Настройки → Сторонние
плагины*, чтобы работало оформление Zenith.

Названия языков, цвета и иконки взяты из Code Styler (MIT), а его иконки — из
[vscode-icons](https://github.com/vscode-icons/vscode-icons) (MIT).
