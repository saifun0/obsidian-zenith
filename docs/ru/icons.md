# Свои иконки

[← Документация](../../README.ru.md) · [English](../en/icons.md) · **Русский**

Везде, где Zenith принимает имя иконки — тип контента, трекер дневника, папка, кнопка
боковой панели, — подойдёт либо встроенное имя (lucide), либо свой идентификатор вида
`zi:<пак>/<имя>` из пака иконок.

**Паки иконок.** Положите папку с файлами `.svg` в папку `icons/` внутри плагина:

```
icons/
  acme/
    pack.json     ← необязательно: { "name": "Acme Icons", "author": "Acme Inc" }
    logo.svg      → zi:acme/logo
    mark.svg      → zi:acme/mark
```

Они появляются вверху каждого выбора иконки, над встроенным набором. **Настройки →
Оформление → Паки иконок** показывают, что загрузилось, и — что полезнее — называют каждый
отвергнутый файл и причину. Россыпь файлов вместо манифеста — сознательный выбор: обычный
сценарий здесь это распаковать что-то скачанное.

**Что принимается.** Только SVG — он наследует `currentColor` и остаётся чётким от 11px до
56px, а PNG-логотип не умеет ни того ни другого. Каждый файл очищается перед сохранением:
`<script>`, `<style>`, `<image>`, `<foreignObject>` и ссылки отвергаются сразу (с указанием
виновного элемента), обработчики `on*` и внешние `href` вырезаются, а внутренние `id` каждой
иконки уводятся в своё пространство имён, чтобы два логотипа не подрались за общий
`<linearGradient id="a">`. Размер файла ограничен 64 КБ.

Очистка нужна потому, что пак иконок — это просто файлы, скопированные пользователем из
интернета.
