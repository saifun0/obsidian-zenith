# API модулей

[← Документация](../../README.ru.md) · [English](../en/module-api.md) · **Русский**

Модуль реализует `IModule` (см. [`src/core/IModule.ts`](../../src/core/IModule.ts)).
Базовый класс `BaseModule` берёт на себя идемпотентную регистрацию экранов и команд и
активацию экрана:

```ts
import { BaseModule } from '../../core/IModule';

export class MyModule extends BaseModule {
    readonly id = 'my-module';
    readonly name = 'My Module';
    readonly description = 'Does something useful.';
    readonly icon = 'sparkles'; // имя иконки lucide

    async onload(): Promise<void> {
        this.registerView(MY_VIEW_TYPE, (leaf) => new MyView(leaf, this.plugin));
        this.addCommand({ id: 'open-my', name: 'Open My Module', callback: () => this.activateView() });
    }

    async onunload(): Promise<void> { /* снять виджеты и прочее */ }

    async activateView(): Promise<void> {
        await this.openView(MY_VIEW_TYPE);
    }
}
```

## Виджеты дашборда

Любой модуль может добавить виджет на дашборд из своего `onload()` и обязан снять его в
`onunload()`:

```ts
const dispose = this.plugin.registerDashboardWidget({
    id: 'my-module.summary',   // id с пространством имён — по нему же группируется в галерее
    title: 'My Summary',
    description: 'Что показывает этот виджет, одной строкой.',
    icon: 'sparkles',
    sizes: ['sm', 'md'],       // размеры, из которых сможет выбрать пользователь
    defaultSize: 'sm',
    order: 50,                 // меньше — рисуется раньше
    component: MySummary,      // React-компонент…
    // …либо монтирование в DOM, не привязанное к фреймворку, — для сторонних модулей на чистом JS:
    // mount: (el, ctx) => { el.setText('hi'); return () => {}; },
});
```

Кнопка **Изменить раскладку** на дашборде включает режим правки: карточки перетаскиваются
(или выделяются и двигаются стрелками), у каждой выбирается размер, а виджеты добавляются и
убираются из галереи снизу. Галерея показывает весь каталог, сгруппированный по модулям, с
живым превью того, сколько места займёт каждый виджет; уже размещённые остаются в списке —
кликом по ним их можно снять.

**Сама сетка тоже настраивается** из того же режима: колонки (2–6), высота строки, зазор и
предельная ширина всего полотна (фиксированная или **Full** — до краёв панели).

Ширина виджета меряется в колонках. Пресеты `S`/`M`/`L` пропорциональные (половина сетки,
вся ширина, вся ширина и двойная высота), поэтому сами по себе они выглядят одинаково при
любом числе колонок; а вот **степпер размаха** рядом (`2/4`) задаёт точную ширину — ради
этого колонки и добавляют: в шесть колонок в ряд помещаются три карточки шириной 2 там, где
в четыре влезали две. Повторный выбор пресета сбрасывает ручной размах.

Смена числа колонок переупаковывает раскладку в порядке чтения, поэтому виджеты встают
парами в появившееся место, а не съезжают вниз. Ручной размах сохраняется как задан и лишь
поджимается, пока сетка уже, — так что при расширении задуманная ширина возвращается. Сетка
откатывается в одну колонку, когда панель узкая *или* когда выбранные колонки оказались бы
уже 120px каждая.

## Кнопки навигации

Модуль **Навигация** рисует на дашборде лаунчер: по кнопке на каждое зарегистрированное
действие. Ему принадлежит виджет, но не кнопки — каждый модуль приносит свою, поэтому
лаунчер перечисляет ровно то, что загружено, и экран, пришедший со сторонним модулем, стоит
рядом с родными:

```ts
const dispose = this.plugin.registerNavAction({
    id: 'my-module.view',      // id с пространством имён — он же хранится в списке скрытых
    label: 'My Module',        // или `labelKey`, если нужен перевод
    description: 'Что находится за этой кнопкой.',
    icon: 'sparkles',
    order: 70,                 // меньше — раньше
    viewType: MY_VIEW_TYPE,    // показать открытую панель или открыть вкладку…
    // …либо, для модуля без собственного экрана:
    // onClick: ({ app }) => new MyModal(app).open(),
});
```

Клик показывает ту панель, где экран уже открыт, а не плодит дубликаты — кнопки уже открытых
экранов помечены точкой. Ctrl/Cmd-клик (или клик средней кнопкой) принудительно открывает
новую вкладку. **Настройки → Навигация** переключают раскладку между сеткой и списком,
выключают подписи ради лаунчера из одних иконок и прячут отдельные кнопки; список скрытых
строится из реестра, поэтому сторонние кнопки тоже прячутся.

Регистрация не зависит от того, включён ли лаунчер, — модулю никогда не приходится проверять,
активна ли Навигация, прежде чем предложить путь к своему экрану.

## Сторонние модули

Собранные модули кладутся в папку `modules/<id>/` внутри плагина (каждый со своим
`manifest.json` и `main.js`, экспортирующим класс модуля). Они находятся при загрузке и
появляются в **Настройках → Активные модули → Сторонние**. Идентификаторы модулей
ограничены `[A-Za-z0-9_-]`, поскольку становятся сегментом пути. Манифест может нести и блок
`translations`, чтобы модуль назвал себя на языке читателя ещё до того, как запустится хоть
строчка его кода, — см. [Язык](language.md).
