# Функции

[← Документация](../../README.ru.md) · [English](../en/features.md) · **Русский**

Zenith устроен так, чтобы всё, чем вы не пользуетесь, можно было выключить. Уровней два:

- **Модули** — *Настройки → Активные модули*. Выключенный модуль не делает ничего. Какие
  модули работают, хранится **на каждом устройстве своё**: на телефоне их может быть меньше,
  чем на компьютере.
- **Функции** — части модуля, без которых можно обойтись. Страница настроек каждого модуля
  начинается с группы **«Функции»**; некоторые стоят рядом с настройками, которые от них
  зависят (запись в дневную заметку — рядом с заголовком, под который она пишет; напоминания
  о намазе — рядом с тем, за сколько минут). Функции **общие** для всех ваших устройств.

Выключено — значит выключено: выключенная функция ничего не рисует, не пишет, не ходит в сеть
и не ставит таймеры. То, что она уже записала, остаётся на месте — выключенный таймер не
стирает `⏱` из задач, а включённый снова опять их показывает. Подробности:

- **Таймер задач** — если выключить его, пока он идёт, отсчёт останавливается и время
  записывается в задачу: кнопки, чтобы остановить его, больше нет.
- **Блок отметок** — выключенный, блок `zenith-daily` вместо трекеров дня пишет об этом одной
  строкой, а новые дневные заметки создаются без блока.
- **Виджеты** — выключенный виджет уходит с дашборда так же, как виджет выключенного модуля.
- **Группировки и виды** — выбранная и потом выключенная группировка задач или вид
  календаря запоминаются до возвращения; до тех пор список идёт без групп, а календарь
  показывает месяц.

[Профили](profiles.md) переключают многое из этого разом — шаблон, сохранённый набор или
присланный кем-то.

Функции может быть нужна другая функция или другой модуль: тепловая карта — часть
статистики задач, запись в дневную заметку требует модуля «Дневник». Такая функция
показана выключенной и говорит, чего ждёт.

## Список

| Модуль | Функции |
| --- | --- |
| — | Иконки папок, кнопка заготовки хранилища |
| [Уведомления](notifications.md) | Центр уведомлений |
| Дашборд | Сегодняшняя дата, фон, сохранённые раскладки |
| Задачи | Запись в дневную заметку, ввод обычной фразой, захват по ссылкам (по умолчанию выключен), напоминания (по умолчанию выключены), подзадачи, вложения, таймер, перетаскивание, группы по дате, группы по заметкам, статистика, тепловая карта, виджет |
| Календарь | Неделя и день, все 24 часа, перенос по часовой сетке, список, ленты от начала до срока, задачи из дневных заметок, подсветка при наведении, виджет «Неделя вперёд», полоса просроченных |

| Дневник | Блок отметок, цвет календаря по настроению, месяц привычек, цели на неделю и пределы, привычки «бросить», год в пикселях, вопрос дня (по умолчанию выключен), счётчик слов, статистика, виджет отметок |
| Контент | Полка «Продолжить», кнопка «+1», выбор нескольких, фильтр по жанру, импорт, статистика, виджет |

У модулей, которые делают одно дело, — навигатора, картинки, медиа-баннера — своих функций
нет: переключатель модуля и есть переключатель функции.

## Существующие настройки

Обновление сохраняет всё, что было: каждая включённая функция записывается включённой в ваши
настройки, так что никакая будущая смена значения по умолчанию не выключит её за вашей
спиной. Переключатели, которые были до функций (`weatherShowAir`, `prayerShowSunrise`,
`journalCaptureTasks`, `dashboardShowDate`…), сохраняют имена и значения — функция читает и
пишет их.
