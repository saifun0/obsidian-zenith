# Профили

[← Документация](../../README.ru.md) · [English](../en/profiles.md) · **Русский**

Профиль — это целиком то, как вы пользуетесь Zenith: какие [модули](features.md) работают,
какие функции включены и настройки к ним — одним целым, которое можно применить, сохранить,
отменить и передать другому. *Настройки → Профили.*

## Шаблоны

| Шаблон | Что настраивает |
| --- | --- |
| Минимум | Дашборд, задачи и дневник — без дополнений. |
| Всё | Все модули и все функции. |
| Привычки и дневник | Дневник со всеми видами трекеров; задачи в самом простом виде. |
| Задачи и планирование | Задачи, календарь и проекты со всеми инструментами; дневник — только как место для захваченных задач. |
| Намаз и пост | Время намаза, напоминания и отметки; дневник в минимуме, чтобы их записывать. |
| Чтение и медиа | Библиотека контента со всеми инструментами. |

Шаблон говорит только за свои модули и не трогает остальное: функции модуля, который он
выключает, остаются как были, и если потом включить модуль снова, он вернётся таким, каким
вы его оставили. **Синхронизацию** не трогает ни один шаблон: выбрать «Минимум» не значит
попросить устройства перестать договариваться. Не решает шаблон и **«Жизнь в неделях»** —
ей нужна дата рождения: она включается только вручную, и шаблон оставляет её как есть.

Новая установка один раз предлагает шаблоны при первом запуске. Тем, кто обновляется, это
окно не показывается — их настройки сохраняются как профиль **«До профилей»**.

## Применение

Ничего не применяется без предпросмотра: что включится, что выключится и сколько настроек
изменится. Два режима:

- **Заменить** — всё, о чём говорит профиль, станет как в нём. То, чего он не касается,
  останется.
- **Добавить к текущему** — только включает модули и функции, включённые в профиле. Ничего
  не выключается, настройки не меняются.

После применения кнопка **«Вернуть как было»** вверху страницы восстанавливает ровно то, что
это применение изменило. Она хранится на каждом устройстве своя — как и изменение, которое
отменяет.

Модуль из профиля, который не установлен, пропускается и попадает в список. Сторонний
модуль, о котором профиль молчит, никогда не выключается.

## Свои профили

**«Сохранить текущий набор»** сохраняет модули, функции и настройки как сейчас под именем —
вместе с папками и местоположением, ведь это ваше же хранилище. Свои профили общие для всех
ваших устройств. В меню каждого: переименовать, экспорт, удалить.

## Экспорт и импорт

**Экспорт** пишет профиль в `Zenith/profiles/<имя>.json` в хранилище — никогда поверх
существующего файла, вместо этого к имени добавляется номер — или копирует его в буфер: так
профиль переносится на телефон. Два переключателя, оба по умолчанию выключены:

- **Включить папки** — у другого человека в хранилище другие папки.
- **Включить местоположение** — где вы находитесь, для погоды и времени намаза.

**Не экспортируется никогда, что бы вы ни выбрали:** пароли, токены, настройки сервера и
синхронизации, пароль шифрования, сторонние модули и их настройки, расстановка дашборда.

**Импорт** читает `.json`-файл из хранилища или вставленный текст. Каждая настройка
проверяется по этой версии Zenith; неизвестное или неподходящее по типу пропускается и
показывается в предпросмотре. Профиль из более новой версии Zenith всё равно пригоден во всём,
что эта версия понимает, — если только у него не новее сама версия формата: тогда нужно
сначала обновить плагин.

## Файл

```json
{
  "zenith": "profile",
  "version": 1,
  "name": "Мой минимум",
  "createdAt": "2026-09-23",
  "modules": ["dashboard", "tasks", "journal"],
  "features": { "tasks.timer": false, "tasks.subtasks": true },
  "settings": { "uiDensity": "compact", "journalTrackers": [] }
}
```

В `features` — идентификаторы со страницы [Функции](features.md); в `settings` — имена
настроек самого плагина. Обычный JSON, который можно прочитать и поправить руками.
