# Приватность

[← Документация](../../README.ru.md) · [English](../en/privacy.md) · **Русский**

Виджет погоды находит место по **городу**, который вы ввели (его ищет геокодинг Open-Meteo),
или по местоположению самого устройства, которое затем называет `api.bigdatacloud.net`.
Определение по IP-адресу через `ipapi.co` — только если вы его включили. Прогноз и качество
воздуха, если оно показано, приходят с Open-Meteo; он получает координаты. Ключи API не
нужны, результаты кэшируются локально.

Время намаза в режиме календаря приходит с `api.aladhan.com`: он получает место,
округлённое примерно до километра, настройки расчёта и часовой пояс устройства — раз в год
для каждого места и метода. В режиме расчёта время намаза запросов не делает.

Библиотека контента сама в сеть не обращается. Обложка, заданная ссылкой, загружается с этого
адреса при каждом показе — как любая картинка в заметке.
