# Приватность

[← Документация](../../README.ru.md) · [English](../en/privacy.md) · **Русский**

Виджет погоды на дашборде определяет местоположение либо по явно указанному **городу**
(Настройки → Погода) через геокодинг Open-Meteo, либо — если город не задан — по
приблизительному местоположению запросом к `ipapi.co`, с откатом на запрос геолокации в
браузере. Данные о погоде берутся из Open-Meteo. Ключи API не нужны, результаты кэшируются
локально.
