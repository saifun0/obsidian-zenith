# Zenith

[English](README.md) · **Русский**

Органайзер жизни для [Obsidian](https://obsidian.md): **дашборд**, **задачи**, **дневник**
ежедневных заметок и **трекер контента** (книги, фильмы, сериалы, игры…). Всё построено на
модульной архитектуре — возможности включаются и выключаются по отдельности, не заставляя
выходить из хранилища.

Данные остаются обычным Markdown в вашем хранилище. Zenith читает и пишет простые файлы
`.md`; никакой скрытой базы данных нет.

## Модули

| Модуль | Что делает |
| --- | --- |
| **Дашборд** | Приветствие, часы, погода, быстрое добавление и сводные виджеты от каждого модуля. |
| **Навигация** | Виджет-лаунчер и боковая панель с кнопкой на каждый экран Zenith — любой модуль может добавить свою — и кнопками для частых команд. |
| **Search** | Одна строка, чтобы найти любой вид, действие, задачу, проект, материал или заметку за день и добавить задачу. |
| **Задачи** | Разбор, фильтрация, поиск, группировка, создание, правка, выполнение и удаление задач. |
| **Дневник** | Ежедневные заметки на календаре, настраиваемые трекеры привычек, шкал и чисел, задачи дня. |
| **Контент** | Галерея и статистика: оценки с половинами звёзд, статусы, прогресс, обложки из хранилища или по ссылке, импорт из MyAnimeList / Goodreads / Letterboxd. Работает без сети. |
| **Намаз** | Время намаза, рассчитанное на устройстве, обратный отсчёт до следующего и учёт прочитанного — в заметке дня. |
| **Медиа-баннер** | GIF или картинка (из хранилища или по ссылке) над деревом файлов, с выбором. |

Модули включаются и выключаются в **Настройках → Активные модули**. Загрузка и выгрузка
происходят мгновенно — перезапускать Obsidian не нужно.

## Сеть

У Zenith нет аккаунта, телеметрии и своего сервера. В сеть он ходит только за этим и только
пока эта возможность включена:

- **Погода** — прогноз с `api.open-meteo.com` и качество воздуха с
  `air-quality-api.open-meteo.com`, если эта строка показана. Передаются только координаты.
- **Поиск места** — город, введённый в настройках, ищется на `geocoding-api.open-meteo.com`.
  Если попросить определить место по устройству, его название берётся с `api.bigdatacloud.net`.
  Определение по IP-адресу через `ipapi.co` — только если вы его включили.
- **Время намаза** — в режиме календаря год опубликованного расписания с `api.aladhan.com`;
  место округляется примерно до километра. В режиме расчёта запросов нет.
- **Синхронизация файлов заметок** — только с сервисом, который вы подключили: Dropbox,
  OneDrive, S3 или WebDAV, по желанию со сквозным шифрованием. Синхронизация настроек сама в
  сеть не ходит: она едет вместе с хранилищем тем способом, которым вы его уже синхронизируете.
- **Обложки**, заданные ссылкой, загружаются с этого адреса, как любая картинка в заметке.

Подробнее — в разделе [Приватность](docs/ru/privacy.md).
